# ups-battery-monitor (Go)

Легковесная фоновая утилита для Windows, которая отслеживает состояние питания компьютера через WMI (`Win32_Battery`), отправляет уведомления о событиях в Telegram-бот и корректно выключает ПК при критическом разряде батареи.

## 🚀 Особенности

* **Минимум ресурсов**: Потребляет всего **~3–5 МБ ОЗУ** и 0% ЦП.
* **Без консольного окна**: Скомпилированный бинарник работает в чистом фоновом режиме.
* **Устойчивость к кратковременным скачкам**: Поддерживает задержку перед отправкой уведомления (`DELAY_NOTIFY`).
* **Бесконечный мониторинг**: Не завершает работу при восстановлении питания, а возвращается в режим ожидания.
* **Автономность**: Все параметры конфигурируются через файл `.env`.

## ⚙️ Настройка конфигурации (`.env`)

Создайте файл `.env` в корневой директории проекта (можно скопировать из `_env.example`):

```env
TELEGRAM_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
TELEGRAM_CHAT_ID=987654321
CHECK_INTERVAL=1
DELAY_NOTIFY=5
LOG_FILE=ups_log.txt
SHUTDOWN_THRESHOLD=5
SHUTDOWN_TIMEOUT=30

```

### Описание параметров:

| Параметр | Описание | Значение по умолчанию |
| --- | --- | --- |
| `TELEGRAM_TOKEN` | Токен Telegram-бота от `@BotFather` | *Обязательно* |
| `TELEGRAM_CHAT_ID` | Ваш Telegram Chat ID | *Обязательно* |
| `CHECK_INTERVAL` | Интервал опроса WMI в секундах | `1` |
| `DELAY_NOTIFY` | Задержка перед отправкой алертов (в секундах) | `5` |
| `LOG_FILE` | Имя файла для записи логов | `ups_log.txt` |
| `SHUTDOWN_THRESHOLD` | Порог заряда батареи (%) для выключения ПК | `5` |
| `SHUTDOWN_TIMEOUT` | Таймер ожидания выключения Windows (`shutdown /s /t`) | `30` |

## 💻 Сборка и Запуск

### 1. Установка зависимостей

```bash
go mod tidy

```

### 2. Тестовый запуск (в режиме отладки)

```bash
go run main.go

```

### 3. Компиляция оптимального фонового `.exe`

Для сборки компактного бинарника без консольного окна и отладочной информации:

```bash
go build -ldflags="-w -s -H windowsgui" -o ups-battery-monitor.exe main.go

```

## 🔄 Настройка автозапуска в Планировщике задач Windows

1. Нажмите `Win + R`, введите `taskschd.msc` и нажмите **Enter**.
2. Нажмите **Создать задачу...** (Create Task).
3. **Вкладка Общие (General):**
* Имя: `ups-battery-monitor`
* Отметьте: *Выполнять для всех пользователей* и *Выполнять с наивысшими правами*.


4. **Вкладка Триггеры (Triggers):**
* Создайте триггер: **При входе в систему** (At log on).


5. **Вкладка Действия (Actions):**
* Действие: *Запуск программы*.
* Программа или сценарий: укажите абсолютный путь к `ups-battery-monitor.exe` (например, `C:\Program Files\ups-battery-monitor\ups-battery-monitor.exe`).
* **Рабочая папка (Start in):** укажите путь к папке с проектом (например, `C:\Program Files\ups-battery-monitor\`), чтобы приложение корректно нашло `.env` файл!


6. **Вкладка Условия (Conditions):**
* Снимите галочку *Запускать только при питании от электросети* (чтобы задача работала и от батареи).

## 🛑 Остановка и Управление процессом

Так как утилита работает без окна, завершить её можно через **Диспетчер задач** (процесс `ups-battery-monitor.exe`) или с помощью команды в консоли:

```cmd
taskkill /f /im ups-battery-monitor.exe

```
